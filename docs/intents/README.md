# Archived intents

The files here are history. They are left as written, even where they use forms hivekit no longer parses into a command.

New intents must give every `[auto]` criterion a command: a trailing code span on the bullet (``- [auto] tests pass: `npm test` ``) or a ```` ```check ```` block under it. An `[auto]` without a command is graded from the code and labelled `auto (unverified)`.
